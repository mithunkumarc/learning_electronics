#### rotor(ac or dc) can be permanent magnet or electromagnet
> if rotor is electromagnet, it can be brushed or brush-less
- type of brush-less
- it can be electromagnet
- stator field coil create changing magnetic field and it reaches rotor and current pass in rotor, rotor becomes electromagnet.

> type of brushed
- dc brushed - dc current copper split ring used
- ac brushed - ac current itself change direction and magnetic poles reverse in motor automatically.



| Motor Type | Rotor Type | Stator Type | How Current/Field is Commutated |
| :--- | :--- | :--- | :--- |
| **Brushed DC** | Electromagnet (Windings) | Permanent Magnet or Electromagnet | **Mechanical:** Brushes + Split-ring Commutator. |
| **Brushed AC (Universal)** | Electromagnet (Windings) | Electromagnet | **Mechanical:** Brushes + Split-ring Commutator (Ac current change direction so are magnetic poles). |
| **Brushless DC / AC Synchronous** | Permanent Magnet | Electromagnet (Windings) | **Electronic:** An external controller/inverter switches the stator coils. |
| **AC Induction (Brushless)** | Electromagnet (Induced) | Electromagnet (Windings) | **Natural Induction:** The AC stator field induces a current directly into the rotor bars. |
